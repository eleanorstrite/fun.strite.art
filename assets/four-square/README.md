# Story Time artwork

- `story-time.jpg`: matching copy of the Story Time children-and-book illustration supplied in the conversation, from https://visit.york.wa.gov.au/Profiles/visitors/Assets/ClientData/Images/Events/York_Storytime.jpg .
- `story-send.svg`: a local vector rendering of the supplied red circular Send-arrow reference, retaining its white rounded arrow and silver beveled rim.

The game loads these assets locally. It does not hotlink images from another website.
